# Постоянные правила Codex — SWEET EMPIRE

- Работать поэтапно. Текущий этап — 0B, подготовка Godot-проекта.
- Не переходить к следующему этапу без явного разрешения пользователя.
- Использовать Godot 4, GDScript и Compatibility Renderer для Windows PC. Python — для обучения модели прогнозирования спроса.
- Не удалять существующие игровые механики и пользовательские ресурсы.
- Перед изменениями читать состояние проекта и Git; сохранять пользовательские изменения и историю.
- Не выполнять разрушительные Git-операции: reset --hard, clean с удалением файлов, принудительный push, удаление веток или переписывание истории без явного разрешения.
- Не выполнять git push без разрешения пользователя. Не менять глобальную конфигурацию Git без необходимости.
- После изменений проводить подходящие проверки. Godot проверять по журналу редактора и коду завершения, а не только результату PowerShell.
- Не запускать два экземпляра Godot для одного проекта.
- Не утверждать, что тесты пройдены, если они не запускались; отсутствие тестов не считать успешным тестированием.
- Отчитываться об изменениях, выполненных проверках, ограничениях и оставшихся действиях.
- Не сохранять пароли, токены, ключи или лицензионные данные в проекте и отчётах.
- Соблюдать лицензии и ограничения прав среды. Не отключать средства безопасности Windows.
- Не перезаписывать существующий проект или документацию без проверки содержимого.
