# SWEET EMPIRE — правила проекта

- Текущий разрешённый этап — 5: косметический магазин. Историческая отметка 0B в родительском AGENTS.md не описывает нынешний проект. Не начинать этап 6 без явного разрешения пользователя.
- Использовать существующий Godot 4.7.2 / GDScript / Compatibility для Windows PC. Не создавать новый проект, не выполнять Git-команды.
- Сохранять пользовательские ресурсы и игровые механики. Перед существенными изменениями читать README и отчёты этапов, делать резервные копии затрагиваемых файлов.
- Общая сессия находится в autoload GameSession. MainMenu → Shop не запускает BakeryGame. Возврат из кондитерской хранит тот же узел вне SceneTree; Continue возвращает его, без повторного ready и создания новой кампании.
- CrystalWallet общий для кампании и магазина. Покупка атомарна, владение связано с одноразовым debit ledger. Не сбрасывать кристаллы, покупки или кампанию при переходах сцен.
- Во время Rush расходуется только подтверждённый баланс до попытки. Постоянные покупки отражаются в checkpoint; откат не должен возвращать потраченные кристаллы или отменять косметику.
- Косметика меняет только визуальные узлы/материалы. Не менять коллизии, маршруты, Product ID, цены, время производства, Utility AI или ML-признаки.
- Не добавлять магазин в игровой HUD, hotkey3 или торгового NPC. Вход только из MainMenu.
- Сохранения на диск не реализованы. Stage6 должен отдельно согласовать сериализацию и восстановление мира; новые косметические данные уже имеют get_save_data/load_save_data.
- Не запускать два Godot для этого проекта одновременно. Проверять журналы, RESULT и настоящий exit code, а не только статус PowerShell. Не заявлять о тестах/ручной игре/FPS без выполнения.
- Сохранять прежние regression suites; после изменений запускать подходящие headless/GPU проверки. Результаты и ограничения документировать. Не менять защиту Windows, не сохранять секреты в репозитории.
