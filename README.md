# SWEET EMPIRE

Этап 0B — подготовка Godot-проекта. Игровые механики не реализованы.

Стек: Godot 4 + GDScript, Compatibility Renderer; Windows PC, 3D low-poly, изометрическая камера. Python — будущее обучение модели прогнозирования спроса. Редактор кода: VS Code + Codex CLI.

Проект находится в `sweet-empire/project.godot`. Импортируйте этот файл в Godot и нажмите F6 для сцены `scenes/main.tscn` либо F5 для проекта. Стартовая сцена — пустой Node3D с ортографической изометрической камерой; пустой фон при запуске ожидаем.

Структура сцен, скриптов, ресурсов, тестов и ML находится внутри `sweet-empire/`. Актуальная документация — в корневой `Documentation/`; `sweet-empire/Documentation/` зарезервирована для документации ресурсов проекта. Старые `Assets/` и `Tools/` сохранены. `Tools/Test-Stage0Project.ps1` — историческая проверка прежнего стека, к Godot неприменима.

См. [окружение](Documentation/Environment.md), [план](Documentation/DevelopmentRoadmap.md) и [отчёт этапа 0B](Documentation/Stage0B-Report.md). Прежние документы сохранены в `Documentation/History/Before-Stage0B/`, журнал `Documentation/Stage0-Log.md` не изменён.
