## Git

Git работает. Репозитория, коммитов, активной ветки и remotes здесь нет. `.gitignore` и `.gitattributes` подготовлены. Глобальные настройки не менялись, push не выполнялся.

После создания и проверки настоящего проекта в сессии с правом записи Git-метаданных:

1. Проверить существующий `.git`, `git status` и пользовательские изменения. Для существующего репозитория сохранить историю и ветки.
2. Только для нового репозитория выполнить `git init -b main` в корне проекта.
3. Просмотреть состав файлов, проверить исключения `git check-ignore Library/probe Temp/probe Obj/probe Logs/probe Builds/probe UserSettings/probe`, убедиться, что `.meta`, Assets, Packages и ProjectSettings остаются отслеживаемыми.
4. Добавить только просмотренные файлы и Unity-ресурсы через явные пути; проверить `git diff --cached --stat` и `git diff --cached`. Не включать секреты и посторонние файлы.
5. Сделать первоначальный коммит при отсутствии посторонних пользовательских изменений. Если не задан автор, запросить имя/email, затем задать их только локально; не придумывать идентичность.
6. После первого коммита создать отсутствующие `develop` и `feature/stage-01-vertical-slice`; существующие ветки не менять. По умолчанию оставить активной main до согласования начала разработки.
