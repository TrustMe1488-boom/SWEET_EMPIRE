# SWEET EMPIRE — план разработки

Стек: Godot 4 + GDScript + Python ML. Windows PC, 3D low-poly, изометрическая камера, Compatibility Renderer.

Текущий этап 0B ограничен окружением, структурой, минимальной сценой, Git и документацией. Игровая разработка не начата. Для каждого следующего этапа требуется явное разрешение пользователя и согласование критериев приёмки.

| Этап | Цель |
|---|---|
| 0B | Подготовка и проверка Godot-проекта |
| 1 | Vertical Slice: минимальный полный цикл кондитерской и проверяемая Windows-сборка |
| 2 | Производство: рецепты, оборудование, производственный цикл |
| 3 | Покупатели: заказы, очередь, обслуживание |
| 4 | Экономика: закупки, склад, расходы, цены, сохранения |
| 5 | Развитие: улучшения, расширение, прогрессия |
| 6 | Контент: интерфейсы, обучение, звук, визуальная доработка |
| 7 | Стабилизация: баланс, оптимизация, тестирование, выпуск |

Python ML предназначен для обучения модели прогнозирования спроса. Данные, метрики и способ интеграции согласовать отдельно; зависимости и модель на этапе 0B не устанавливаются. Каталог `tools/ml` зарезервирован внутри Godot-проекта.
